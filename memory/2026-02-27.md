## Issues Found

### 1. Broken Models Symlink
- **Problem:** Symlink at `~/.openclaw/agents/main/qmd/xdg-cache/qmd/models` → `/home/node/.cache/qmd/models`
- **Reality:** `/home/node/.cache/qmd/models` does not exist
- **Fix:** Created symlink to `~/.bun/install/cache` (QMD's actual cache location)

### 2. QMD Not Installed
- **Problem:** `which qmd` returned nothing
- **Cause:** No installation in accessible PATH
- **Fix:** Installed QMD globally to workspace: `bun install -g qmd`

### 3. Missing tsx Dependency
- **Problem:** QMD requires tsx to run TypeScript
- **Fix:** Installed with `bun add -g tsx`

### 4. Bun Installation Challenges
- **Problem:** Standard bun install to `~/.bun` fails with permission errors in Docker
- **Cause:** Can't write to `/usr/local/lib/node_modules/`
- **Fix:** Installed bun to workspace: `BUN_INSTALL="$HOME/.openclaw/workspace/.bun" curl ...`

## Installation Completed

### Persistent Paths Created
```
~/.openclaw/workspace/.bun/          ← Bun installation (persists)
~/.local/bin/qmd                    ← QMD wrapper script (persists)
~/.bun/install/cache/                ← QMD models cache (persists)
```

## What QMD Is

QMD is a **local semantic search system** for OpenClaw memory:
- Uses local AI models (Gemma 300M via node-llama-cpp) - no API keys!
- Hybrid search: BM25 (keywords) + vectors (semantic) + reranking
- Works completely offline
- Auto-downloads models on first use
- Stores embeddings in SQLite with sqlite-vec

## Key Lessons

1. **Workspace paths matter** - System paths (`/usr/local`, `~/.npm`) don't persist in Docker
2. **Symlink issues are common** - QMD models symlink breaks often, needs explicit fix
3. **Wrapper scripts essential** - Set up environment variables correctly
4. **Ask before installing** - QMD takes ~10 minutes, should warn user
